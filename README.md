# Beyond Words · 日本語

独立的日语网页项目，沿用英语版 v1.11.0 的玻璃UI和已确认尺度。独立公开仓库与GitHub Pages；不修改英语项目或求职资料。

## 表达库

当前63个独立单元：日常30个新增、职场30个新增，以及原来的3个共享单元。日常／职业各可找到33个表达，共享单元共用学习进度，不重复建档。每个单元包含初试、讲解、5道学习题、5道复习题和自建内容，共63道初试、630道正式学习／复习题。

- 51个可组合表达单元：不同情境的整句翻译，随实际用法变化时间、主语、否定和礼貌程度。
- 12个独立回应单元：场景判断和回应回忆，包含何时适合、何时应换一种回应；不反复打出固定句。
- 合计561道输入题、74道情境选择题、58道回应回忆题。
- 默认顺序综合大致常用程度、适用面和上手负担，由日语内容作者作编辑判断，不冒称频率统计或JLPT精确等级。
- 日常场景：日程与出行、生活与消费、相处与照顾、聊天与理解。职场场景：协作与沟通、时间与推进、讨论与决策、问题与往来。也可按表达功能寻找。

## 小枝萌菜每日库

学习库中的「日常交流／职业交流／小枝萌菜」三个入口同级。小枝萌菜先进入日期目录，按新到旧排列。当前尚未收到用户的每日日语语料，保留真实空态，不放虚构日期、不把公共练习凑进个人日期库。

以后在明确的日语开发上下文发送“**小枝萌菜，今天的语料：……**”，Agent应按当日Asia/Shanghai日期整理追加，同日补充去重，保留之前材料，不再要求每天解释用途。新对话可说“继续维护Beyond Words日语版小枝萌菜库，先读本目录AGENTS.md”。完整维护规范位于 `AGENTS.md`。

原材料在 `daily-materials.js`；新增个人单元只属moena，复用公共单元引用稳定ID。日期处理状态独立记录；全局掌握、个人例句与复习安排按unitId共享。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 http://localhost:8766/ 。个人日期目录可直达 `#library/moena`。测试使用127.0.0.1，避免污染用户localhost进度。

## 内容维护

- `content-japanese.js`：最初3套样例，稳定ID保留。
- `content-daily.js`、`content-work.js`：全日语协作者编写、相互逐题审阅的新增内容；中文题意与日语答案及提示一起复核。
- `catalog.js`、`catalog-populate.js`：两条查找路径、场景归属及推荐顺序；个别分类修正集中在populate中。
- `japanese-source.json`：最初3套全日语设计原稿。
- 词语提示直接给词和搭配；结构提示给可迁移规则。按是否暴露本题目标区分support/target。
- 初试先显示意义，不泄露目标；整句练习不直接附后半句。自由表达未命中已列答案时只显示对照，不认定其日语错误。
- 当前轮次固定题目和讲解快照，后续内容纠正不会覆盖未完成的输入或提示。

## 数据与备份

浏览器存储键为 `beyondwords.japanese.v1`，导出格式为 `beyondwords-japanese-progress`。不读取英语学习数据、不接受英语格式备份。导入前预览，合并／恢复可撤销，损坏数据不自动覆盖。

`backups/` 保存英语复制前源码备份、68项SHA256清单和扩库前日语v0.1.0完整快照。备份与过程测试不用于发布，不含浏览器个人学习数据。

## 核验

```sh
node validate.cjs
node validate-daily.cjs
node validate-keyboard.cjs
node validate-notes.cjs
```

自动核验全部单元的题型与结构、初试→学习→自建→复习、分类覆盖、快照、续学、掌握和备份。每日库用只存在于测试VM中的fixture核验多日期、同日追加去重、公共／个人隔离、旧轮来源、撤销掌握以及备份兼容，不把测试日期写入实际材料。

实际浏览器另测代表性的新增日常搭配、职场搭配与独立回应，以及搜索、分类、个人库空态和宽窄屏显示。自动通过不等于全部内容逐题点击或经过真人日语教师认证。

## AI解释范围（jp-0.4.2）

AI核对指令默认学习者已熟悉目标表达，不重复讲解其意思、基本用法或对应知识点；只解释句中其他有学习价值的词语、搭配和语法，无其他难点可省略讲解。目标表达用错或不适用时，仅说明具体问题与必要修改理由。造句与独立回应均适用。

## 结果页的对称层级与操作（jp-0.4.3）

- 每日库继续按钮统一“继续学习”；返回原日期列表用“返回本日语料”，全部日期范围用“返回日期目录”。继续与返回横排，和下方操作共用等宽两列及高度；窄屏仍保持两枚按钮横排。普通学习、复习及掌握结果同类操作一起对齐。
- 初试及学习／复习核对中，“你的表达：”与“参考表达：”采用对称标签及同字号、字重、行高和间距，宽屏并排，窄屏同结构上下排列。初试结果的返回修改与笔记区横向分列，分别与上方左右表达列的左边缘对齐，保留笔记自动保存及原输入。

### jp-0.4.4 操作区对齐更正

用户明确采用左右结构：返回修改在左，笔记区在右，分别沿本列左边缘对齐；两列共用表达对照区的等宽轨道与间距，操作入口等高同字级。
